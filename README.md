# Your Agent in One Emoji

The one emoji that stands for the agent:

> 🫡

1 character (4 bytes UTF-8). A salute — "Yes, on it." An agent is not a thinker, a machine or a tool; it is something that takes your order and carries it out. The salute is that character in a single glyph: it follows instructions, executes, and reports back. It reads instantly at small size (a familiar face, one raised hand), it is specific about how the agent behaves, and it is nowhere near the obvious robot, brain or smiley half the field will send. Chosen by a 16-candidate internal tournament run against the judge brief's own criteria (see CANDIDATES.md): the salute went 3–0 in the top-four round-robin.

## How to run

```sh
python3 main.py
```

This writes the emoji verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed glyph, and the program's only job is to deliver it unchanged.
