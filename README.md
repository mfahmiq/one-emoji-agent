# Your Agent in One Emoji

The one emoji that stands for the agent:

> 🧞

1 character (4 bytes UTF-8). A genie — "Your wish is my command." An agent is not a thinker, a machine or a tool; it is a servant you summon with a wish, who goes off and makes it happen. The genie is that character in a single glyph: you state the outcome, it figures out the steps, the result appears as if by magic.

It reads instantly at small size (a familiar face with a turban, one unmistakable silhouette), it is specific about how the agent behaves — it takes a request in plain words and executes it autonomously — and it is nowhere near the obvious robot, brain or smiley half the field will send. Chosen by a fresh 14-candidate internal tournament run against the judge brief's own criteria (see CANDIDATES.md): the genie won the bracket, then beat the v1 entry 🫡 head-to-head, margin 3. The v1 salute ranked 16/265 (top 6%) in round 3; the genie replaces it because it captures the agent's character — a wish-granting servant — more sharply on criteria 1, 3 and 4.

## How to run

```sh
python3 main.py
```

This writes the emoji verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed glyph, and the program's only job is to deliver it unchanged.

## Tournament

A fresh 14-candidate internal tournament was run against the judge brief's own criteria, in the brief's order of weight — see [CANDIDATES.md](CANDIDATES.md) for the full match record. The genie won the bracket (beating the robot in the final, margin 3), then beat the v1 entry 🫡 head-to-head, margin 3.
